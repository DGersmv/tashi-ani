# ✅ Простое решение

## 📝 Файл .env создан заново

Файл `.env` пересоздан через простую команду `echo`.

---

## ⚠️ ВАЖНО: Проверьте файл вручную!

**Откройте файл `.env` в редакторе (VS Code или блокнот) и убедитесь что там:**

1. **ТОЛЬКО одна строка:**
   ```
   DATABASE_URL=postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require
   ```

2. **БЕЗ кавычек!**
   - ❌ Неправильно: `DATABASE_URL="postgresql://..."`
   - ✅ Правильно: `DATABASE_URL=postgresql://...`

3. **БЕЗ пробелов в начале или конце строки!**

4. **БЕЗ пустых строк до или после!**

---

## 🚀 Если файл правильный - выполните:

```powershell
npx prisma generate
npx prisma migrate deploy
```

---

## 🆘 Если все еще не работает

**Попробуйте установить переменную окружения напрямую:**

```powershell
$env:DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require"
npx prisma migrate deploy
```

**Это временно установит переменную в текущей сессии PowerShell.**

---

**Сначала проверьте файл .env вручную!**
