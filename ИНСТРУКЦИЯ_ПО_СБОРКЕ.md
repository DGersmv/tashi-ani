# 📦 Инструкция по сборке проекта

## ⚠️ Проблема с API routes

Next.js пытается экспортировать API routes как статические страницы, но они требуют сервера. Так как мы используем PHP API, эти routes не нужны для статического экспорта.

## ✅ Решение

**Вариант 1: Временное переименование (рекомендуется)**

Перед сборкой временно переименуйте папку `src/app/api` в `src/app/_api`:

```powershell
# Перед сборкой
Rename-Item -Path "src/app/api" -NewName "_api"

# Сборка
npm run build

# После сборки верните обратно
Rename-Item -Path "src/app/_api" -NewName "api"
```

**Вариант 2: Использовать только build:dist**

Скрипт `build:dist` автоматически обработает всё:

```powershell
npm run build:dist
```

Это создаст папку `dist` с:
- Статическим экспортом Next.js (папка `out`)
- PHP API файлами
- config.php
- .htaccess

## 📤 После сборки

Загрузите содержимое папки `dist` на хостинг через FileZilla.

---

**Примечание:** Если сборка всё равно не работает, можно просто собрать frontend отдельно и загрузить PHP API отдельно.
