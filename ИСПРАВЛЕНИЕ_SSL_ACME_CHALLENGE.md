# 🔧 Исправление проблемы с SSL сертификатом (ACME Challenge)

## ❌ Проблема

```
DNS problem: NXDOMAIN looking up TXT for _acme-challenge.tashi-ani.ru
```

Это означает, что Let's Encrypt не может найти TXT записи для проверки домена.

## 🔍 Причина

1. **DNS записи еще не обновились** после изменения IP адреса
2. **TXT записи для ACME challenge не созданы** в DNS
3. **DNS кэш** еще содержит старые записи

## ✅ Решение

### Вариант 1: Подождать и повторить (рекомендуется)

1. **Подождите 30-60 минут** после изменения DNS записей
2. **Проверьте, обновился ли DNS:**

```bash
# В Windows PowerShell
nslookup tashi-ani.ru
nslookup www.tashi-ani.ru

# Должен вернуться: 31.31.196.254
```

3. **Проверьте TXT записи:**

```bash
# Проверить TXT записи
nslookup -type=TXT _acme-challenge.tashi-ani.ru
```

4. **Повторите получение сертификата** в панели reg.ru:
   - Мои домены → tashi-ani.ru → SSL-сертификаты
   - Нажмите "Обновить" или "Получить сертификат"

### Вариант 2: Вручную добавить TXT записи (если нужно)

Если reg.ru не создает TXT записи автоматически:

1. **Войдите в панель reg.ru**
2. **Перейдите:** Мои домены → tashi-ani.ru → DNS-серверы и зона
3. **Добавьте TXT запись:**

| Имя | Тип | Значение | TTL |
|-----|-----|----------|-----|
| `_acme-challenge` | TXT | (значение из лога reg.ru) | 3600 |

**ВАЖНО:** Значение TXT записи должно быть из лога reg.ru (токен для подтверждения)

### Вариант 3: Использовать HTTP проверку вместо DNS

Если DNS проверка не работает, можно использовать HTTP проверку:

1. **В панели reg.ru** выберите метод проверки: **HTTP** вместо **DNS**
2. **Убедитесь, что сайт доступен** по HTTP: `http://tashi-ani.ru`
3. **Повторите получение сертификата**

## 🔍 Диагностика через SSH

Выполните в SSH для проверки:

```bash
# 1. Проверить DNS записи
dig tashi-ani.ru A
dig www.tashi-ani.ru A

# 2. Проверить TXT записи
dig _acme-challenge.tashi-ani.ru TXT

# 3. Проверить, доступен ли сайт
curl -I http://tashi-ani.ru
curl -I https://tashi-ani.ru
```

## ⏱️ Временное решение

Пока SSL сертификат не получен, сайт будет работать по HTTP:

1. **Проверьте доступность по HTTP:**
   ```
   http://tashi-ani.ru
   ```

2. **После получения SSL** сайт автоматически заработает по HTTPS

## 📋 Чек-лист

- [ ] Повторена попытка получения сертификата в панели reg.ru
