## 🎯 Вы сейчас в psql (видно приглашение `postgres=>`)

**Выполните команду для просмотра списка баз данных:**

```sql
\l
```

**Это покажет все базы данных на кластере reg.ru.**

---

## 📋 Что делать после просмотра списка БД

### Вариант А: Использовать существующую БД (рекомендуется)

1. **Найдите одну из существующих БД** в списке (кроме `postgres`, `template0`, `template1`)
2. **Запишите её имя** (например: `db1`, `mydb`, или что-то другое)
3. **Выйдите из psql:** `\q`
4. **Создайте файл `.env`** в корне проекта с содержимым:
   ```
   DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/ИМЯ_СУЩЕСТВУЮЩЕЙ_БД?sslmode=require"
   ```
   Замените `ИМЯ_СУЩЕСТВУЮЩЕЙ_БД` на реальное имя БД из списка!

### Вариант Б: Обратиться в поддержку reg.ru

Если хотите создать новую БД `tashi_ani_prod`:
1. **Выйдите из psql:** `\q`
2. **Обратитесь в поддержку reg.ru** и попросите:
   - Создать новую БД `tashi_ani_prod`
   - Или выдать права пользователю `admin` на создание БД
3. **После создания БД** создайте файл `.env`:
   ```
   DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/tashi_ani_prod?sslmode=require"
   ```

## ✅ После создания `.env` файла

**Выполните в PowerShell:**

```powershell
# 1. Сгенерировать Prisma Client
npx prisma generate

# 2. Применить миграции
npx prisma migrate deploy

# 3. Мигрировать данные из SQLite
npm run db:migrate-data
```
