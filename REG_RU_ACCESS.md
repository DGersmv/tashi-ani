# 🔑 Доступ к серверу через reg.ru

## Проблема
Пароль не работает, возможно сервер настроен только на SSH ключи.

## ✅ Решения

### Вариант 1: Доступ через веб-консоль reg.ru

1. **Зайдите в панель управления reg.ru:**
   - Откройте https://www.reg.ru/
   - Войдите в личный кабинет
   - Перейдите в раздел "Хостинг" или "VPS"

2. **Найдите ваш сервер:**
   - IP: `89.104.67.209`
   - Найдите раздел "Управление сервером" или "Консоль"

3. **Откройте веб-консоль (VNC/Web SSH):**
   - В панели reg.ru должна быть кнопка "Консоль" или "Web SSH"
   - Это позволит подключиться к серверу через браузер без SSH

4. **После входа в консоль выполните:**
```bash
cd /var/www/tashi-ani
pm2 status
pm2 logs tashi-ani --lines 50
pm2 restart tashi-ani
```

### Вариант 2: Использовать SSH ключ из reg.ru

Если вы нашли ключ `2a:82:f3:dd:6e:e2:50:e2:45:58:75:7d:14:60:26:e1` в панели reg.ru:

1. **Скачайте приватный SSH ключ из панели reg.ru:**
   - В панели управления найдите раздел "SSH ключи" или "Доступ к серверу"
   - Скачайте приватный ключ (файл с расширением `.pem` или без расширения)

2. **Сохраните ключ на вашем компьютере:**
   ```powershell
   # Создайте директорию .ssh если её нет
   if (!(Test-Path "$env:USERPROFILE\.ssh")) {
       New-Item -ItemType Directory -Path "$env:USERPROFILE\.ssh"
   }
   
   # Сохраните ключ в файл (замените содержимое на ваш ключ)
   # Файл должен называться: id_rsa_regru или regru_key
   ```

3. **Подключитесь используя ключ:**
   ```powershell
   ssh -i "$env:USERPROFILE\.ssh\regru_key" root@89.104.67.209
   ```

### Вариант 3: Сброс пароля через панель reg.ru

1. **В панели управления reg.ru:**
   - Найдите ваш VPS сервер
   - Перейдите в "Управление" → "Пароли" или "Доступ"
   - Нажмите "Сбросить пароль root" или "Установить новый пароль"

2. **Установите новый пароль:**
   - Придумайте новый пароль
   - Сохраните его в безопасном месте

3. **Подключитесь с новым паролем:**
   ```powershell
   ssh root@89.104.67.209
   ```

### Вариант 4: Добавить ваш SSH ключ через веб-консоль

1. **Подключитесь через веб-консоль reg.ru** (см. Вариант 1)

2. **На сервере добавьте ваш публичный ключ:**
   ```bash
   # Создайте директорию если её нет
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   
   # Откройте файл authorized_keys
   nano ~/.ssh/authorized_keys
   ```

3. **На вашем компьютере скопируйте публичный ключ:**
   ```powershell
   # Если у вас есть SSH ключ
   cat "$env:USERPROFILE\.ssh\id_rsa.pub"
   
   # Если ключа нет, создайте его:
   ssh-keygen -t rsa -b 4096
   ```

4. **Вставьте публичный ключ в файл authorized_keys на сервере**

5. **Установите правильные права:**
   ```bash
   chmod 600 ~/.ssh/authorized_keys
   ```

6. **Теперь можно подключаться без пароля:**
   ```powershell
   ssh root@89.104.67.209
   ```

## 🔍 Что означает ключ `2a:82:f3:dd:6e:e2:50:e2:45:58:75:7d:14:60:26:e1`

Это **MD5 fingerprint** SSH ключа сервера. Он используется для проверки подлинности сервера.

**Проверка fingerprint сервера:**
```powershell
# Подключитесь и проверьте
ssh-keyscan 89.104.67.209 | ForEach-Object { ssh-keygen -lf $_ }
```

## 🚀 Быстрое решение проблемы "нет сети"

После получения доступа к серверу (любым способом):

```bash
# 1. Перейти в директорию проекта
cd /var/www/tashi-ani

# 2. Проверить статус приложения
pm2 status

# 3. Если приложение не запущено
pm2 restart tashi-ani
# или
pm2 start ecosystem.config.js

# 4. Проверить логи
pm2 logs tashi-ani --lines 50

# 5. Проверить переменные окружения
pm2 env 0

# 6. Проверить файл .env.local
cat .env.local
```
