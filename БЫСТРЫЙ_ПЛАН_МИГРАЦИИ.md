### Шаг 1: Создать БД на reg.ru ⏭️

**Подключиться к reg.ru и создать базу:**

```powershell
# Если psql добавлен в PATH:
$env:PGPASSWORD="Gdv2210974!"
psql -h 79.174.89.232 -p 15555 -U admin -d postgres

# Или полный путь:
$env:PGPASSWORD="Gdv2210974!"
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h 79.174.89.232 -p 15555 -U admin -d postgres
```

**В psql выполнить:**

```sql
-- Создать базу данных
CREATE DATABASE tashi_ani_prod;

-- Выдать права
\c tashi_ani_prod
GRANT ALL ON SCHEMA public TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO admin;

-- Проверить
\c postgres
\l

-- Выйти
\q
```

## 🆘 Если что-то не работает

**Проблема: Не могу подключиться к reg.ru**
- Проверьте что кластер запущен в панели reg.ru
- Проверьте правильность хоста, порта, логина, пароля
- Попробуйте через веб-интерфейс reg.ru (если доступен)

**Проблема: Ошибка при миграции данных**
- Убедитесь что шаг 3 выполнен (миграции применены)
- Проверьте что `.env.local` содержит правильную строку подключения
- Проверьте что файл `prisma/dev.db` существует

**Проблема: psql не найден**
- См. `ДОБАВИТЬ_PSQL_В_PATH.md`
- Или используйте полный путь к psql.exe
