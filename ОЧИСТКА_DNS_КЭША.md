# 🔄 Очистка DNS кэша Windows

## ❌ Проблема

`nslookup` показывает старый IP `89.104.67.209` вместо нового `31.31.196.254`.

Это означает, что DNS кэш на вашем компьютере еще не обновился.

## ✅ Решение

### Шаг 1: Очистить DNS кэш Windows

Выполните в PowerShell (от администратора):

```powershell
# Очистить DNS кэш
ipconfig /flushdns

# Обновить DNS записи
ipconfig /registerdns

# Проверить результат
nslookup tashi-ani.ru
```

### Шаг 2: Если не помогло - использовать другой DNS сервер

Временно измените DNS сервер на Google DNS:

1. Откройте **Настройки сети** Windows
2. Найдите ваше подключение (Ethernet или Wi-Fi)
3. Измените DNS на:
   - **Предпочитаемый:** `8.8.8.8`
   - **Альтернативный:** `8.8.4.4`
4. Сохраните и проверьте снова

### Шаг 3: Проверить через онлайн сервисы

Проверьте DNS через онлайн сервисы (они покажут актуальные записи):

1. **https://dnschecker.org**
   - Введите: `tashi-ani.ru`
   - Выберите тип: `A`
   - Нажмите "Search"
   - Должен показать `31.31.196.254` по всему миру

2. **https://www.whatsmydns.net**
   - Введите: `tashi-ani.ru`
   - Выберите тип: `A`
   - Проверьте результат

### Шаг 4: Проверить напрямую по IP

Пока DNS не обновился, можно проверить сайт напрямую по IP:

1. Откройте файл `C:\Windows\System32\drivers\etc\hosts` (от администратора)
2. Добавьте строку:
   ```
   31.31.196.254 tashi-ani.ru www.tashi-ani.ru
   ```
3. Сохраните файл
4. Откройте `http://tashi-ani.ru` в браузере

**ВАЖНО:** После обновления DNS удалите эту строку из hosts!

## ⏱️ Время обновления DNS

- **Локальный кэш:** очищается сразу после `ipconfig /flushdns`
- **Провайдер DNS:** 5-30 минут
- **Глобально:** до 24 часов (редко)

## 🔍 Проверка через SSH

Выполните в SSH на сервере:

```bash
# Проверить DNS записи на сервере
dig tashi-ani.ru A +short
dig www.tashi-ani.ru A +short

# Должно вернуть: 31.31.196.254
```

## ✅ После очистки кэша

1. Выполните `ipconfig /flushdns`
2. Подождите 1-2 минуты
3. Проверьте снова: `nslookup tashi-ani.ru`
4. Должен вернуться: `31.31.196.254`
