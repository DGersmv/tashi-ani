# 🔧 Настройка MySQL на reg.ru хостинге

## 📋 Данные для подключения

На reg.ru хостинге обычно используются следующие данные:

- **Хост:** `localhost` (или IP адрес, если указан в панели)
- **Порт:** `3306` (стандартный для MySQL)
- **База данных:** `u3269198_default`
- **Пользователь:** `u3269198` (или `u3269198_default` - проверьте в панели)
- **Пароль:** (ваш пароль от БД, который вы задали при создании)

## 🔍 Где найти данные подключения

1. Войдите в панель управления reg.ru
2. Перейдите в раздел "Базы данных MySQL"
3. Найдите базу `u3269198_default`
4. Там будут указаны:
   - Имя пользователя
   - Пароль (или возможность его изменить)
   - Хост (обычно `localhost`)

## ⚙️ Настройка config.php

Откройте `config.php` и обновите строку подключения:

```php
// Для reg.ru MySQL хостинга
define('DATABASE_URL', 'mysql://u3269198:ВАШ_ПАРОЛЬ@localhost:3306/u3269198_default');
```

**Замените:**
- `u3269198` - на ваше реальное имя пользователя
- `ВАШ_ПАРОЛЬ` - на ваш реальный пароль
- `localhost` - на хост, если указан другой
- `u3269198_default` - на имя базы, если отличается

## 🔄 Миграция данных

Если у вас уже есть данные в PostgreSQL, их нужно будет мигрировать в MySQL.

**Важно:** PostgreSQL и MySQL имеют различия в синтаксисе SQL, поэтому:
1. Нужно будет адаптировать SQL запросы
2. Или использовать инструмент миграции данных

## ✅ Проверка подключения

После настройки `config.php`, можно проверить подключение:

```php
<?php
require_once 'api/db.php';
try {
    $db = getDbConnection();
    echo "✅ Подключение к MySQL успешно!";
} catch (Exception $e) {
    echo "❌ Ошибка: " . $e->getMessage();
}
?>
```

## ⚠️ Важные замечания

1. **Различия PostgreSQL и MySQL:**
   - В MySQL используются обратные кавычки для имен таблиц: `` `table_name` ``
   - В MySQL `true/false` это `1/0`, а не `'t'/'f'`
   - В MySQL нет типа `BOOLEAN`, используется `TINYINT(1)`
   - Различия в функциях (например, `NOW()` работает одинаково, но есть другие отличия)

2. **Адаптация кода:**
   - Все SQL запросы в PHP файлах нужно проверить на совместимость с MySQL
   - Особенно проверки типа `=== 't'` нужно заменить на `=== '1'` или `== 1`

3. **Prisma:**
   - Если используете Prisma, нужно изменить `schema.prisma`:
     ```prisma
     datasource db {
       provider = "mysql"
       url      = env("DATABASE_URL")
     }
     ```
