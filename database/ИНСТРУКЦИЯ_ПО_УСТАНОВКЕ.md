# 📋 Инструкция по установке базы данных

## ⚠️ Ошибка "#1046 - No database selected"

Если вы получили эту ошибку, значит не выбрана база данных перед выполнением SQL.

## ✅ Решение

### Вариант 1: Выбрать базу в phpMyAdmin (рекомендуется)

1. Войдите в phpMyAdmin на reg.ru
2. **ВАЖНО:** В левом меню выберите базу данных `u3269198_default`
3. После выбора базы, перейдите на вкладку "SQL"
4. Скопируйте содержимое `mysql-schema.sql`
5. Вставьте в окно SQL
6. Нажмите "Выполнить"

### Вариант 2: SQL файл уже содержит USE statement

Я обновил файл `mysql-schema.sql` - теперь он автоматически выбирает базу данных в начале:
```sql
USE `u3269198_default`;
```

Просто выполните весь скрипт - он сам выберет нужную базу.

## 🔍 Проверка

После выполнения скрипта проверьте:

1. В левом меню phpMyAdmin должна быть видна база `u3269198_default`
2. В ней должно быть 15 таблиц:
   - users
   - objects
   - projects
   - project_stages
   - photo_folders
   - photos
   - panoramas
   - panorama_comments
   - photo_comments
   - documents
   - messages
   - verification_codes
   - bim_models
   - bim_model_comments
