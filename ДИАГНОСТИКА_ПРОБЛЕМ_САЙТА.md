# 🔍 Диагностика проблем с сайтом tashi-ani.ru

## ❌ Проблема: "Нет соединения"

### Шаг 1: Проверить DNS (обновился ли IP)

```bash
# В Windows PowerShell
nslookup tashi-ani.ru

# Должен вернуться: 31.31.196.254
# Если вернулся старый IP (89.104.67.209) - DNS еще не обновился
```

**Если DNS не обновился:**
- Подождите 10-30 минут
- Или очистите DNS кэш: `ipconfig /flushdns`

### Шаг 2: Проверить доступность сервера

```bash
# Проверить, отвечает ли сервер
ping 31.31.196.254

# Проверить HTTP порт
telnet 31.31.196.254 80

# Проверить HTTPS порт
telnet 31.31.196.254 443
```

### Шаг 3: Проверить через SSH

Подключитесь к серверу и проверьте:

```bash
# Проверить, запущен ли веб-сервер
sudo systemctl status httpd
# или
sudo systemctl status nginx
# или
sudo systemctl status apache2

# Проверить, есть ли файлы сайта
ls -la ~/public_html
# или
ls -la /var/www/html
# или
ls -la ~/www
```

### Шаг 4: Проверить, загружены ли файлы

```bash
# Найти, где должен быть сайт
# Обычно это одна из папок:
ls -la ~/public_html/
ls -la ~/www/
ls -la /var/www/html/
ls -la /home/u3269198/public_html/

# Проверить, есть ли index.html
find ~ -name "index.html" -type f 2>/dev/null
```

## ✅ Что нужно сделать

### 1. Загрузить файлы на хостинг

Если файлы еще не загружены:

1. **Откройте FileZilla**
2. **Подключитесь к серверу:**
   - Хост: `31.31.196.254` (или `server257.hosting.reg.ru`)
   - Пользователь: `u3269198`
   - Пароль: (ваш пароль от хостинга)
   - Порт: `22` (SFTP) или `21` (FTP)

3. **Найдите папку для сайта:**
   - Обычно это: `/home/u3269198/public_html/` или `/home/u3269198/www/`
   - Или спросите в техподдержке reg.ru

4. **Загрузите ВСЁ содержимое папки `dist`:**
   - Выберите все файлы из `E:\tashi-ani\dist`
   - Перетащите в папку сайта на сервере

### 2. Проверить права доступа

```bash
# Установить правильные права
cd ~/public_html  # или где ваш сайт
chmod 755 .
chmod 644 *.html *.php
chmod 755 api
find api -type f -exec chmod 644 {} \;
find api -type d -exec chmod 755 {} \;
```

### 3. Проверить .htaccess

```bash
# Проверить, есть ли .htaccess
ls -la ~/public_html/.htaccess

# Проверить содержимое
cat ~/public_html/.htaccess
```

### 4. Проверить config.php

```bash
# Проверить, есть ли config.php
ls -la ~/public_html/config.php

# Проверить права доступа (должен быть 644)
chmod 644 ~/public_html/config.php
```

## 🔧 Быстрая проверка через SSH

Выполните эти команды в SSH:

```bash
# 1. Проверить веб-сервер
sudo systemctl status httpd || sudo systemctl status nginx || sudo systemctl status apache2

# 2. Найти папку сайта
echo "Проверяю возможные папки:"
ls -la ~/public_html/ 2>/dev/null && echo "✓ Найден public_html"
ls -la ~/www/ 2>/dev/null && echo "✓ Найден www"
ls -la /var/www/html/ 2>/dev/null && echo "✓ Найден /var/www/html"

# 3. Проверить, есть ли index.html
find ~ -name "index.html" -type f 2>/dev/null | head -5

# 4. Проверить логи ошибок
sudo tail -20 /var/log/httpd/error_log 2>/dev/null || sudo tail -20 /var/log/nginx/error.log 2>/dev/null
```
