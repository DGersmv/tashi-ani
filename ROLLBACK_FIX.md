# 🔄 Откат к рабочей версии

## Проблема
После обновления кода сайт перестал работать. Нужно вернуться к рабочей версии.

## ✅ Быстрое решение: Откат через Git

### Шаг 1: Найдите последний рабочий коммит
В веб-консоли:
```bash
cd /var/www/tashi-ani
git log --oneline -10
```

Найдите коммит ДО обновления (например, `5a0bd0a` или тот, который был до `cc56c11`).

### Шаг 2: Откатитесь к рабочей версии
```bash
# Откатите код (но сохраните изменения)
git reset --hard 5a0bd0a

# Или если знаете точный коммит
git reset --hard HEAD~1
```

### Шаг 3: Перезапустите приложение БЕЗ пересборки
```bash
pm2 restart tashi-ani
```

**ВАЖНО:** Не запускайте `npm run build` - используйте старую сборку!

## 🔍 Альтернатива: Восстановить .next из бэкапа

Если есть бэкап директории .next:
```bash
# Восстановите .next
cp -r /path/to/backup/.next /var/www/tashi-ani/

# Перезапустите
pm2 restart tashi-ani
```

## 📝 Самый простой способ

```bash
cd /var/www/tashi-ani
git reset --hard 5a0bd0a
pm2 restart tashi-ani
```

## ✅ После отката

1. Проверьте сайт - должен заработать
2. Проблема с входом в кабинет останется, но сайт будет работать
3. Потом исправим проблему с входом аккуратно, без ломания всего
