### Шаг 2: Создать файл `.env`

**⚠️ ВАЖНО: Prisma читает переменные из `.env`, а не из `.env.local`!**

**Создайте файл `.env` в корне проекта (`e:\tashi-ani\.env`):**

**Вариант А: Если используете существующую БД (рекомендуется)**

```bash
# .env
DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/ИМЯ_СУЩЕСТВУЮЩЕЙ_БД?sslmode=require"
```

**Замените `ИМЯ_СУЩЕСТВУЮЩЕЙ_БД` на имя одной из существующих БД (из Шага 1).**

**Вариант Б: Если поддержка reg.ru создаст новую БД**

```bash
# .env
DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/tashi_ani_prod?sslmode=require"
```

**⚠️ ВАЖНО:** 
- Пароль для reg.ru: `Gdv2210974!` (с восклицательным знаком!)
- Это НЕ пароль от локального PostgreSQL
- Не коммитьте `.env` в git!
