# ✅ Решение: Установить переменную напрямую

## 🔧 Проблема

Prisma не находит DATABASE_URL из файла `.env`, хотя файл существует.

## ✅ Решение: Установить переменную окружения напрямую в PowerShell

**Выполните эти команды в PowerShell:**

```powershell
# Установить переменную окружения
$env:DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require"

# Проверить что установлено
$env:DATABASE_URL

# Теперь применить миграции
npx prisma migrate deploy
```

**Это установит переменную в текущей сессии PowerShell и Prisma её увидит!**

---

## 📝 Полная последовательность команд

**Выполните все команды по порядку:**

```powershell
# 1. Установить переменную окружения
$env:DATABASE_URL="postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require"

# 2. Сгенерировать Prisma Client (если еще не сделано)
npx prisma generate

# 3. Применить миграции
npx prisma migrate deploy

# 4. Мигрировать данные из SQLite
npm run db:migrate-data
```

---

## ⚠️ Важно

- Переменная `$env:DATABASE_URL` действует **только в текущей сессии PowerShell**
- Если закроете PowerShell и откроете новый - нужно установить переменную снова
- Или используйте файл `.env` (но сейчас он почему-то не работает)
