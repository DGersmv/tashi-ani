# 🔧 Исправление ошибки "Неверный пароль и пользователь"

## Проблема
После настройки `.env.local` появляется ошибка "Неверный пароль и пользователь". Это происходит потому, что **пользователь с таким email не существует в базе данных** или пароль не захеширован правильно.

## ✅ Решение: Создать/обновить пользователя в базе данных

### Шаг 1: Подключитесь к серверу
```bash
ssh root@89.104.67.209
```

### Шаг 2: Перейдите в директорию проекта
```bash
cd /var/www/tashi-ani
```

### Шаг 3: Убедитесь, что .env.local настроен правильно
```bash
cat .env.local
```

Должны быть установлены:
- `MASTER_ADMIN_EMAIL="2277277@bk.ru"`
- `MASTER_ADMIN_PASSWORD="admin123"`
- `JWT_SECRET="your-secret-key"`
- `DATABASE_URL="file:./dev.db"`

### Шаг 4: Запустите скрипт создания админа
```bash
node create-admin-user.js
```

Этот скрипт:
- Создаст пользователя с email из `MASTER_ADMIN_EMAIL`
- Установит пароль из `MASTER_ADMIN_PASSWORD` (правильно захешированный)
- Установит роль `MASTER`
- Установит статус `ACTIVE`

### Шаг 5: Проверьте результат
Вы должны увидеть:
```
✅ Админ создан! (или обновлен)
📋 Данные для входа:
   Email: 2277277@bk.ru
   Пароль: admin123
```

### Шаг 6: Перезапустите приложение (если нужно)
```bash
pm2 restart tashi-ani --update-env
```

### Шаг 7: Попробуйте войти
1. Откройте сайт в браузере
2. Введите email: `2277277@bk.ru`
3. Введите пароль: `admin123`
4. Нажмите "Войти"

## 🔍 Альтернативный способ (если скрипт не работает)

### Вариант 1: Использовать существующий скрипт
```bash
node reset-admin-password.js
```

### Вариант 2: Создать через Prisma Studio
```bash
npx prisma studio
```

Затем в интерфейсе:
1. Откройте таблицу `users`
2. Создайте нового пользователя:
   - `email`: `2277277@bk.ru`
   - `password`: (нужно захешировать через bcrypt)
   - `role`: `MASTER`
   - `status`: `ACTIVE`

### Вариант 3: Через SQL (если используете SQLite)
```bash
# Установите sqlite3 если нет
apt-get install sqlite3

# Откройте базу данных
sqlite3 prisma/dev.db

# Создайте пользователя (пароль должен быть захеширован!)
# Лучше использовать скрипт create-admin-user.js
```

## ⚠️ Важные моменты

1. **Пароль должен быть захеширован** - нельзя просто вставить `admin123` в базу данных
2. **Email должен точно совпадать** - проверьте, нет ли лишних пробелов
3. **Роль должна быть `MASTER`** - не `ADMIN`, а именно `MASTER`
4. **Статус должен быть `ACTIVE`** - иначе вход не сработает

## 🐛 Диагностика проблем

### Проблема: "Пользователь не найден"
**Решение:** Запустите `node create-admin-user.js`

### Проблема: "Неверный пароль"
**Решение:** 
1. Убедитесь, что скрипт правильно захешировал пароль
2. Проверьте, что в `.env.local` правильный `MASTER_ADMIN_PASSWORD`
3. Перезапустите скрипт: `node create-admin-user.js`

### Проблема: Скрипт не запускается
**Решение:**
```bash
# Проверьте, что Node.js установлен
node --version

# Проверьте, что зависимости установлены
npm install

# Проверьте, что база данных существует
ls -la prisma/dev.db

# Если базы нет, создайте:
npx prisma migrate deploy
```
