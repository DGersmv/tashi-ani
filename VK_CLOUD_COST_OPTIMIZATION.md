## 📊 Сравнение конфигураций Managed PostgreSQL (если всё же нужен)

### 💰 Минимальная конфигурация

**1 CPU, 1GB RAM, 20GB SSD**
- **Стоимость:** ~5000₽/месяц (реальная цена!)
- **Подходит для:**
  - Небольшие проекты
  - До 100 активных пользователей
  - Небольшой объём данных (< 5GB)
  - Низкая нагрузка на БД

**Когда увеличивать:**
- Постоянно высокая загрузка CPU (> 80%)
- Нехватка памяти (OOM ошибки в логах)
- Медленные запросы к БД

### ✅ Оптимальная конфигурация

**1 CPU, 2GB RAM, 20GB SSD**
- **Стоимость:** ~6000-7000₽/месяц (реальная цена!)
- **Подходит для:**
  - Средние проекты
  - До 500 активных пользователей
  - Объём данных до 10GB
  - Средняя нагрузка

### 🚀 Высокая нагрузка (только при необходимости!)

**2 CPU, 4GB RAM, 50GB SSD**
- **Стоимость:** ~10000-15000₽/месяц (реальная цена!)
- **Подходит для:**
  - Большие проекты
  - Тысячи пользователей
  - Большой объём данных (> 20GB)
  - Высокая нагрузка

## 💡 Рекомендации по экономии

### 1. Начните с минимальной конфигурации

```bash
# Создайте PostgreSQL с минимальными ресурсами
# 1 CPU, 1GB RAM, 20GB SSD
```

**Почему:**
- В VK Cloud можно легко увеличить ресурсы позже
- Платите только за то, что используете
- Если нагрузка низкая - не переплачиваете

### 2. Мониторинг использования

В панели VK Cloud отслеживайте:
- **CPU usage** - если постоянно > 80% - нужно больше CPU
- **RAM usage** - если постоянно > 90% - нужно больше RAM
- **Disk usage** - если > 80% - нужно больше диска

### 3. Оптимизация запросов

Вместо увеличения ресурсов, сначала оптимизируйте:

```sql
-- Добавьте индексы для частых запросов
CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_photos_object_id ON photos(object_id);

-- Проверьте медленные запросы
SELECT * FROM pg_stat_statements 
ORDER BY total_exec_time DESC 
LIMIT 10;
```

### 4. Используйте connection pooling

Ограничьте количество соединений:

```typescript
// В Prisma можно настроить connection pool
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
  // Ограничиваем соединения
}
```

### 5. Регулярная очистка данных

Удаляйте старые данные:
- Старые коды верификации
- Удалённые записи
- Неиспользуемые файлы

## 📈 Когда увеличивать конфигурацию

### Увеличьте CPU если:
- ✅ CPU постоянно загружен > 80%
- ✅ Медленные запросы к БД
- ✅ Много одновременных пользователей

### Увеличьте RAM если:
- ✅ Частые ошибки "out of memory"
- ✅ Медленная работа при больших запросах
- ✅ Много кэшируемых данных

### Увеличьте диск если:
- ✅ Использование диска > 80%
- ✅ Нет места для бэкапов
- ✅ Растёт объём данных

## 🔄 Как увеличить конфигурацию

В VK Cloud это делается в несколько кликов:

1. Откройте ваш PostgreSQL инстанс
2. Нажмите **"Изменить конфигурацию"**
3. Выберите новую конфигурацию
4. Подтвердите изменение
5. Изменение применится без потери данных (может быть перезагрузка 1-2 минуты)
