## 🔧 Шаг 1: Подготовка (что нужно иметь)

### 1.1 Учетные данные от reg.ru

Вам нужны следующие данные от панели reg.ru:

1. **Логин пользователя БД** (имя пользователя для подключения к PostgreSQL)
2. **Пароль пользователя БД** (пароль для подключения)
3. **Доступ к панели управления reg.ru** (где находится кластер)

**Где найти эти данные:**
- В панели управления reg.ru
- В разделе "Базы данных" → ваш кластер "tashi-ani-db"

**Вариант А: Через веб-интерфейс reg.ru (если доступен)**

**Вариант Б: Через командную строку (psql)**


**Вариант В: Онлайн инструменты**

- Или Docker с PostgreSQL (если установлен)

## 💻 Шаг 3: Подключение через командную строку (альтернативный способ)

### 3.1 Установка PostgreSQL клиента на Windows

**Способ А: Установить PostgreSQL полностью (включает клиент psql)**

1. Скачайте PostgreSQL для Windows: https://www.postgresql.org/download/windows/
2. Запустите установщик
3. Во время установки:
   - Выберите компоненты: установите галочку на **"Command Line Tools"**
   - Пароль для пользователя postgres (запомните его, он нужен только для локального PostgreSQL)
4. После установки откройте командную строку (cmd) или PowerShell

**Способ Б: Только клиент (легче)**

1. Скачайте Portable версию PostgreSQL или используйте онлайн инструменты
2. Или используйте Docker (если установлен)

### 3.2 Подключение через psql

Откройте командную строку (cmd) или PowerShell и выполните:

```bash
# Формат команды:
psql -h 79.174.89.232 -p 15555 -U ВАШ_ЛОГИН -d postgres

# Пример (замените ВАШ_ЛОГИН на ваш логин):
psql -h 79.174.89.232 -p 15555 -U myuser -d postgres

# После ввода команды вам предложат ввести пароль
# Введите пароль (символы не будут отображаться - это нормально)
```

**Если вы видите приглашение типа:**
```
postgres=#
```

**Значит подключение успешно! ✅**

## 🗄️ Шаг 4: Создание новой базы данных

### 4.1 Просмотр существующих баз данных

**В веб-интерфейсе:**
- Обычно слева есть список баз данных
- Найдите раздел "Databases" или "Базы данных"
- Вы увидите список существующих баз (обычно 2 базы, как указано)

**В командной строке (psql):**
```sql
-- Вывести список всех баз данных
\l

-- Или более подробно:
SELECT datname FROM pg_database ORDER BY datname;
```

Вы увидите что-то вроде:
```
   Name    |  Owner   | Encoding |   Collate   |    Ctype    | 
-----------+----------+----------+-------------+-------------+
 postgres  | postgres | UTF8     | en_US.UTF-8 | en_US.UTF-8 |
 template0 | postgres | UTF8     | en_US.UTF-8 | en_US.UTF-8 |
 template1 | postgres | UTF8     | en_US.UTF-8 | en_US.UTF-8 |
 БД1       | user     | UTF8     | ...         | ...         |
 БД2       | user     | UTF8     | ...         | ...         |
```

**Важно:**
- `postgres`, `template0`, `template1` - это системные базы, их трогать не нужно
- `БД1`, `БД2` - это ваши существующие базы (2 штуки)
- Нам нужно создать новую базу данных

### 4.2 Создание новой базы данных

**В веб-интерфейсе:**

1. Найдите кнопку **"Создать базу данных"** или **"Create Database"**
2. Или найдите раздел SQL запросов / SQL редактор
3. Введите SQL команду (см. ниже)

**В командной строке (psql):**

Введите следующую команду:

```sql
CREATE DATABASE tashi_ani_prod;
```

**Нажмите Enter**

**Результат должен быть:**
```
CREATE DATABASE
```

**Если появилась ошибка:**
- Возможно база с таким именем уже существует - используйте другое имя
- Возможно нет прав - обратитесь в поддержку reg.ru

### 4.3 Проверка создания базы

**В веб-интерфейсе:**
- Обновите список баз данных
- Вы должны увидеть новую базу `tashi_ani_prod`

**В командной строке:**
```sql
-- Вывести список баз данных снова
\l

-- Или
SELECT datname FROM pg_database WHERE datname = 'tashi_ani_prod';
```

Вы должны увидеть вашу новую базу данных в списке.

## 👤 Шаг 5: Настройка пользователя и прав доступа

### 5.1 Проверка текущего пользователя

**В командной строке:**
```sql
-- Проверить текущего пользователя
SELECT current_user;

-- Или список всех пользователей
\du

-- Или подробнее
SELECT usename FROM pg_user;
```

Обычно вы увидите имя пользователя, которое вы использовали для подключения.

### 5.2 Проверка прав пользователя на новую БД

**Подключитесь к новой базе данных:**

**В веб-интерфейсе:**
- Выберите базу `tashi_ani_prod` из списка
- Переключитесь на неё

**В командной строке:**
```bash
# Выйти из текущей сессии (если вы в psql)
\q

# Подключиться к новой базе (Windows):
set PGPASSWORD=Gdv2210974!
psql -h 79.174.89.232 -p 15555 -U admin -d tashi_ani_prod

# Или в PowerShell:
$env:PGPASSWORD="Gdv2210974!"
psql -h 79.174.89.232 -p 15555 -U admin -d tashi_ani_prod

# Или если вы уже в psql (и подключены к postgres):
\c tashi_ani_prod
```

**Проверить права:**
```sql
-- Проверить права текущего пользователя
SELECT has_database_privilege(current_user, 'tashi_ani_prod', 'ALL');

-- Должно вернуть: t (true) - значит есть все права
-- Если вернуло: f (false) - нужно выдать права (см. ниже)
```

### 5.3 Выдача прав (если нужно)

**Если права недостаточны, выполните:**

**Подключитесь к системной базе `postgres`:**

```bash
# В командной строке:
\c postgres
```

**Выполните команды выдачи прав:**

```sql
-- Выдать все права на базу данных (для пользователя admin)
GRANT ALL PRIVILEGES ON DATABASE tashi_ani_prod TO admin;
```

**Затем подключитесь к новой базе и выдайте права на схему:**

```sql
-- Подключиться к новой базе
\c tashi_ani_prod

-- Выдать права на схему public
GRANT ALL ON SCHEMA public TO admin;

-- Выдать права на все существующие таблицы (если есть)
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO admin;

-- Выдать права на все последовательности (для AUTO_INCREMENT)
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA public TO admin;

-- Выдать права на будущие таблицы (чтобы не выдавать каждый раз)
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO admin;
```

**✅ Важно:** Используется пользователь `admin` (ваш логин от reg.ru). В большинстве случаев права уже есть, но лучше убедиться.

## 🆘 Решение проблем

### Проблема: Не могу подключиться к кластеру

**Решения:**
1. Проверьте правильность хоста и порта (79.174.89.232:15555)
2. Проверьте логин и пароль
3. Проверьте что кластер запущен в панели reg.ru
4. Проверьте файрвол - возможно нужно разрешить доступ с вашего IP
5. Обратитесь в поддержку reg.ru

### Проблема: Ошибка "permission denied" при создании БД

**Решения:**
1. Убедитесь что вы используете правильного пользователя
2. Возможно у пользователя нет прав на создание БД - обратитесь в поддержку reg.ru
3. Или создайте БД через веб-интерфейс reg.ru (если доступен)

### Проблема: База данных уже существует

**Решение:**
```sql
-- Проверить существующие базы
SELECT datname FROM pg_database;

-- Если база уже существует, можно:
-- 1. Использовать существующую базу
-- 2. Или удалить и создать заново (ОСТОРОЖНО - потеряете данные!)
-- DROP DATABASE tashi_ani_prod;  -- НЕ ДЕЛАЙТЕ ЭТОГО если есть данные!
-- CREATE DATABASE tashi_ani_prod;
```

### Проблема: Не могу найти веб-интерфейс в reg.ru

**Решения:**
1. Обратитесь в поддержку reg.ru - попросите доступ к веб-интерфейсу PostgreSQL
2. Используйте командную строку (psql) - инструкция выше
3. Используйте сторонние инструменты (pgAdmin, DBeaver и т.д.)
