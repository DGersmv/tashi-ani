# 📦 Установка sqlite3

## ❌ Проблема

Скрипт миграции требует модуль `sqlite3`, который не установлен.

## ✅ Решение

**Устанавливаю модуль `sqlite3`...**

После установки снова выполните:
```powershell
npm run db:migrate-data
```

---

**sqlite3 нужен для чтения данных из старой SQLite базы `prisma/dev.db` и переноса их в PostgreSQL.**
