# 📥 Установка PostgreSQL клиента (для подключения к reg.ru)

## 🎯 Цель

Установить инструменты для подключения к кластеру PostgreSQL на reg.ru и создания базы данных.

**Важно:** Вам НЕ нужен полный PostgreSQL сервер! Нужен только клиент для подключения к удаленному серверу.

---

## ⚠️ Важно понимать разницу:

### ❌ PostgreSQL Сервер (полная установка)
- Устанавливает сервер БД на вашем компьютере
- Занимает много места (~200-300 МБ)
- Запускает службу PostgreSQL (которая вам не нужна)
- **Но:** включает клиент psql, который вам нужен

### ✅ PostgreSQL Клиент (только клиент)
- Только инструменты для подключения к удаленному серверу
- Маленький размер (~50 МБ)
- Не запускает службы
- **Но:** на Windows его сложнее найти отдельно

---

## 💻 Варианты для Windows

### Вариант 1: Полная установка PostgreSQL (проще) ✅

**Если вы уже устанавливаете - это нормально!** Продолжайте установку.

**Что делать:**
1. Скачайте PostgreSQL: https://www.postgresql.org/download/windows/
2. Запустите установщик
3. Во время установки:
   - Выберите все компоненты (или хотя бы "Command Line Tools")
   - Пароль для пользователя postgres (запомните, но он нужен только для локального сервера)
   - Порт 5432 (по умолчанию) - можете оставить
4. После установки:
   - Локальный сервер PostgreSQL запустится - это нормально
   - Вы можете его остановить, если не нужен (через Services)
   - Главное - у вас появится psql.exe в папке установки

**Плюсы:**
- ✅ Просто установить
- ✅ Включает все нужные инструменты
- ✅ Работает гарантированно

**Минусы:**
- ❌ Устанавливает лишнее (сервер, который не нужен)
- ❌ Занимает больше места

**Использование:**
После установки откройте командную строку (cmd) или PowerShell и используйте `psql`:

```bash
# Проверить что psql установлен
psql --version

# Должно вывести версию, например: psql (PostgreSQL) 17.0
```

---

### Вариант 2: Только клиент (сложнее найти)

**Для Windows:** 
- Можно найти портативные версии клиента
- Или использовать онлайн инструменты
- Или установить через Chocolatey: `choco install postgresql --params '/Password:postgres'` (только клиент)

**Не рекомендуется** для новичков - сложнее найти и настроить.

---

### Вариант 3: Онлайн инструменты (без установки) ✅

**Можно вообще не устанавливать ничего!**

**Варианты:**
1. **Веб-интерфейс reg.ru** (если доступен)
   - Откройте панель reg.ru
   - Найдите веб-интерфейс для PostgreSQL
   - Создайте БД через веб-интерфейс

2. **pgAdmin Online** или другие онлайн SQL редакторы
   - Работают в браузере
   - Не требуют установки

3. **DBeaver Community Edition** (бесплатный)
   - Визуальный инструмент для БД
   - Поддерживает PostgreSQL
   - Скачать: https://dbeaver.io/download/

## ✅ Если вы УЖЕ устанавливаете PostgreSQL (ваш случай)

**Это нормально! Продолжайте установку.**

**Что делать после установки:**

1. **Проверьте установку:**
   ```bash
   # Откройте командную строку (cmd) или PowerShell
   psql --version
   
   # Должно показать версию PostgreSQL
   ```

2. **Локальный сервер PostgreSQL запустится - это нормально**
   - Вы можете остановить его, если не нужен
   - Или оставить - он не мешает подключению к reg.ru

3. **Подключитесь к reg.ru кластеру:**
   ```bash
   # Windows (cmd):
   set PGPASSWORD=Gdv2210974!
   psql -h 79.174.89.232 -p 15555 -U admin -d postgres
   
   # PowerShell:
   $env:PGPASSWORD="Gdv2210974!"
   psql -h 79.174.89.232 -p 15555 -U admin -d postgres
   ```

4. **Создайте базу данных:**
   ```sql
   CREATE DATABASE tashi_ani_prod;
   ```

**Готово!** Теперь у вас есть все необходимое.

## 🔧 Как остановить локальный PostgreSQL (если не нужен)

Если вы не планируете использовать PostgreSQL локально, можете остановить службу:

**Windows:**
1. Нажмите `Win + R`
2. Введите `services.msc` и нажмите Enter
3. Найдите службу `postgresql-x64-17` (или похожую)
4. Правой кнопкой → Остановить
5. Правой кнопкой → Свойства → Тип запуска: Вручную

**Важно:** Остановка службы не удалит клиент psql - он продолжит работать!
