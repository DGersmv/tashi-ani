# 🤔 Какую БД использовать?

## 📋 Ситуация

Вы говорите что в `.env` указано `tashi_ani_db`, но мы видели в списке только:
- `admin`
- `db1`

**БД `tashi_ani_db` НЕ было в списке!**

---

## ✅ Решение

### Вариант А: Использовать существующую БД `db1` (рекомендуется)

**Файл `.env` должен содержать:**

```
DATABASE_URL=postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require
```

**Плюсы:**
- ✅ БД уже существует
- ✅ Не нужно создавать новую
- ✅ Можно сразу использовать

**Минусы:**
- ⚠️ Если в `db1` уже есть данные - они могут быть перезаписаны при миграции

---

### Вариант Б: Использовать БД `admin`

**Файл `.env` должен содержать:**

```
DATABASE_URL=postgresql://admin:Gdv2210974!@79.174.89.232:15555/admin?sslmode=require
```

**⚠️ Не рекомендуется** - `admin` может быть системной БД.

---

### Вариант В: Создать новую БД `tashi_ani_db`

**Если хотите использовать `tashi_ani_db`:**

1. **Обратитесь в поддержку reg.ru** и попросите создать БД `tashi_ani_db`
2. **После создания** используйте в `.env`:
   ```
   DATABASE_URL=postgresql://admin:Gdv2210974!@79.174.89.232:15555/tashi_ani_db?sslmode=require
   ```

---

## 📝 Рекомендация

**Используйте БД `db1`** - она точно существует и готова к использованию!

**Файл `.env` должен быть:**
```
DATABASE_URL=postgresql://admin:Gdv2210974!@79.174.89.232:15555/db1?sslmode=require
```

---

## ✅ Проверка правильности строки

**Формат должен быть:**
- `postgresql://` - протокол
- `admin` - логин
- `Gdv2210974!` - пароль (с восклицательным знаком!)
- `@79.174.89.232:15555` - хост и порт
- `/db1` - имя БД (или другое если используете)
- `?sslmode=require` - параметр SSL

**Без пробелов, без лишних символов!**

---
