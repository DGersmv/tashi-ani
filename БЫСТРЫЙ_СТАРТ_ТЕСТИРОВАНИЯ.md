## 🔧 Шаг 2: Проверка расширения PostgreSQL

Проверьте, что расширение PostgreSQL доступно в PHP:

```powershell
C:\xampp\php\php.exe -m | findstr pgsql
```

Если расширение не найдено, нужно:
1. Открыть `C:\xampp\php\php.ini`
2. Раскомментировать строки:
   ```ini
   extension=pdo_pgsql
   extension=pgsql
   ```
3. Убедиться, что файлы `php_pdo_pgsql.dll` и `php_pgsql.dll` есть в `C:\xampp\php\ext\`

## 🚀 Шаг 3: Запуск PHP сервера

В одном терминале запустите:

```powershell
npm run php:dev
```

Сервер запустится на `http://localhost:8000`

---

## 🧪 Шаг 4: Тестирование API

### В браузере:

1. **Portfolio API (не требует БД):**
   ```
   http://localhost:8000/api/portfolio.php
   ```
   Должен вернуть JSON с файлами портфолио.

2. **User Profile (требует БД):**
   ```
   http://localhost:8000/api/user/profile.php?email=test@example.com
   ```
   Вернет ошибку, если пользователя нет, или данные пользователя.

### Через скрипт:

В другом терминале (пока сервер работает):

```powershell
npm run php:test
```

---

## ⚠️ Важно для тестирования с БД:

1. **Создан файл `config.php`** с настройками подключения к reg.ru PostgreSQL
2. **Проверьте доступность БД** с вашего IP (может потребоваться добавить IP в whitelist на reg.ru)
3. **Для тестирования без БД** можно использовать только endpoints, которые не требуют БД (например, portfolio.php)
