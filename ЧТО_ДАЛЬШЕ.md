**После подключения (вы увидите приглашение `postgres=#`):**

```sql
-- Создать базу данных
CREATE DATABASE tashi_ani_prod;

-- Выдать права
\c tashi_ani_prod
GRANT ALL ON SCHEMA public TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO admin;

-- Проверить
\c postgres
\l

-- Должна быть видна tashi_ani_prod

-- Выйти
\q
```

## 📝 После создания БД: Применить миграции

**В PowerShell в папке проекта (`e:\tashi-ani`):**

```powershell
# 1. Сгенерировать Prisma Client
npx prisma generate

# 2. Применить миграции к новой БД
npx prisma migrate deploy
```

**Это создаст все таблицы на новой БД!**

---

## 📦 Затем: Мигрировать данные

**После применения миграций:**

```powershell
# Мигрировать данные из SQLite в PostgreSQL
npm run db:migrate-data
```

**Это перенесет все данные из `prisma/dev.db` в новую БД на reg.ru!**

---

## ✅ Проверка

**После миграции данных:**

npx prisma studio

**Откроется в браузере - проверьте что все данные на месте!**
