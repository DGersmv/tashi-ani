# 🚀 Быстрое создание админа на сервере

## Проблема: "Неверный пароль и пользователь"

Это происходит потому, что пользователь с email `2277277@bk.ru` не существует в базе данных.

## ✅ Решение (выполните на сервере):

```bash
# 1. Подключитесь к серверу
ssh root@89.104.67.209

# 2. Перейдите в директорию проекта
cd /var/www/tashi-ani

# 3. Убедитесь, что .env.local настроен
cat .env.local | grep MASTER_ADMIN

# 4. Запустите скрипт создания админа
node create-admin-user.js
```

## 📋 Что делает скрипт:

1. Читает `MASTER_ADMIN_EMAIL` и `MASTER_ADMIN_PASSWORD` из `.env.local`
2. Создает пользователя в базе данных (если его нет)
3. Или обновляет пароль существующего пользователя
4. Правильно хеширует пароль через bcrypt
5. Устанавливает роль `MASTER` и статус `ACTIVE`

## 🔄 После создания:

```bash
# Перезапустите приложение (если нужно)
pm2 restart tashi-ani --update-env

# Проверьте логи
pm2 logs tashi-ani --lines 20
```

## 🐛 Если скрипт не работает:

### Проблема: "Cannot find module 'dotenv'"
**Решение:** Скрипт работает и без dotenv, используя значения по умолчанию. Или установите:
```bash
npm install dotenv
```

### Проблема: "Database connection failed"
**Решение:** Проверьте `DATABASE_URL` в `.env.local`:
```bash
cat .env.local | grep DATABASE_URL
# Должно быть: DATABASE_URL="file:./dev.db"
```

### Проблема: "База данных не существует"
**Решение:** Создайте базу данных:
```bash
npx prisma migrate deploy
```

## 📝 Альтернативный способ (если скрипт не работает):

Используйте существующий скрипт:
```bash
node reset-admin-password.js
```

Этот скрипт создаст/обновит пользователя с email `2277277@bk.ru` и паролем `admin123`.
