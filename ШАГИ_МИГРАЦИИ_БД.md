```powershell

psql -h 79.174.89.232 -p 15555 -U admin -d postgres
```

**Вариант Б: Использовать полный путь (если не добавили в PATH)**

```powershell
# Установить пароль
$env:PGPASSWORD="Gdv2210974!"

# Подключиться к кластеру
& "C:\Program Files\PostgreSQL\17\bin\psql.exe" -h 79.174.89.232 -p 15555 -U admin -d postgres
```

**После подключения (в psql):**

```sql
-- Создать новую базу данных
CREATE DATABASE tashi_ani_prod;

-- Выдать права (если нужно)
\c tashi_ani_prod
GRANT ALL ON SCHEMA public TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON TABLES TO admin;
ALTER DEFAULT PRIVILEGES IN SCHEMA public GRANT ALL ON SEQUENCES TO admin;

-- Проверить создание
\c postgres
\l

-- Выйти
\q
```

**📚 Подробная инструкция:** См. `QUICK_START_DB_CREATION.md` или `CREATE_POSTGRESQL_DB_REG_RU.md`

### Шаг 2: Определить текущую базу данных 🔍

**Нужно узнать какая БД используется сейчас:**

**Вариант А: SQLite** (если используется `DATABASE_URL="file:./prisma/dev.db"` или похожее)
- Файл базы данных: `prisma/dev.db` или `prisma/prod.db`
- Нужно мигрировать через скрипт `scripts/migrate-sqlite-to-postgres.js`

**Вариант Б: PostgreSQL** (если используется `DATABASE_URL="postgresql://..."`)
- Уже PostgreSQL, нужно просто перенести данные
- Можно использовать `pg_dump` / `pg_restore`

**Проверка:**

1. Посмотреть файл `.env.local` (если есть):
   ```bash
   # Посмотреть DATABASE_URL
   ```

2. Проверить есть ли файл SQLite:
   ```bash
   # Проверить наличие SQLite базы
   ls prisma/*.db
   # или
   dir prisma\*.db
   ```

### Шаг 5: Мигрировать данные 📦

**В зависимости от типа текущей БД:**

#### Если текущая БД - SQLite:

```bash
# Убедитесь что DATABASE_URL указывает на новую БД reg.ru
# (уже настроено на шаге 3)

# Запустить скрипт миграции
npm run db:migrate-data
# или
node scripts/migrate-sqlite-to-postgres.js
```

**Скрипт мигрирует все данные в правильном порядке:**
- Users
- Objects
- Projects
- ProjectStages
- PhotoFolders
- Photos
- Panoramas
- Documents
- Messages
- PhotoComments
- PanoramaComments
- BimModels
- BimModelComments
- VerificationCodes

#### Если текущая БД - PostgreSQL:

**Вариант А: Использовать pg_dump / pg_restore**

```bash
# 1. Экспорт из старой БД
pg_dump -h СТАРЫЙ_ХОСТ -p СТАРЫЙ_ПОРТ -U СТАРЫЙ_ПОЛЬЗОВАТЕЛЬ -d СТАРАЯ_БД -F c -f migration.dump

# 2. Импорт в новую БД reg.ru
$env:PGPASSWORD="Gdv2210974!"
pg_restore -h 79.174.89.232 -p 15555 -U admin -d tashi_ani_prod -c -v migration.dump
```

**Вариант Б: Использовать SQL формат**

```bash
# 1. Экспорт в SQL
pg_dump -h СТАРЫЙ_ХОСТ -p СТАРЫЙ_ПОРТ -U СТАРЫЙ_ПОЛЬЗОВАТЕЛЬ -d СТАРАЯ_БД > dump.sql

# 2. Импорт в новую БД
$env:PGPASSWORD="Gdv2210974!"
psql -h 79.174.89.232 -p 15555 -U admin -d tashi_ani_prod -f dump.sql
```
