## ⏳ Что нужно сделать

### 1. Получить данные подключения к MySQL

В панели reg.ru найдите:
- Имя пользователя БД
- Пароль БД
- Хост (обычно `localhost`)
- Имя базы данных (вероятно `u3269198_default`)

### 2. Обновить config.php

Замените в `config.php`:
```php
define('DATABASE_URL', 'mysql://ПОЛЬЗОВАТЕЛЬ:ПАРОЛЬ@localhost:3306/u3269198_default');
```

### 3. Адаптировать SQL запросы для MySQL

**Основные изменения:**

#### a) Булевы значения
PostgreSQL использует `'t'/'f'`, MySQL использует `1/0`:

**Было (PostgreSQL):**
```php
if ($user['is_visible'] === 't') { ... }
```

**Должно быть (MySQL):**
```php
if ($user['is_visible'] == 1 || $user['is_visible'] === '1') { ... }
```

#### b) Имена таблиц и колонок
MySQL чувствителен к регистру и требует обратные кавычки для зарезервированных слов.

#### c) RETURNING (PostgreSQL специфично)
PostgreSQL поддерживает `RETURNING`, MySQL - нет. Нужно использовать `LAST_INSERT_ID()`.

### 4. Обновить Prisma schema

Изменить `prisma/schema.prisma`:
```prisma
datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}
```
