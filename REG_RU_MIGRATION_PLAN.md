Если данные уже в PostgreSQL (другая БД):

**Вариант А: Использование pg_dump / pg_restore**

```bash

# 2. Импорт в новую БД reg.ru

```

**Вариант Б: Использование Prisma (если структура одинаковая)**

Можно адаптировать скрипт `scripts/migrate-sqlite-to-postgres.js` для миграции между PostgreSQL БД.

**Вариант В: Прямое подключение через psql**

```bash
# Экспорт в SQL формат
pg_dump -h СТАРЫЙ_ХОСТ -p СТАРЫЙ_ПОРТ -U СТАРЫЙ_ПОЛЬЗОВАТЕЛЬ -d СТАРАЯ_БД > dump.sql

# Импорт в новую БД
psql -h 79.174.89.232 -p 15555 -U ПОЛЬЗОВАТЕЛЬ -d НАЗВАНИЕ_БД -f dump.sql
```

**⚠️ Важно при миграции данных:**
- Мигрировать данные в правильном порядке (с учетом foreign keys)
- Отключить foreign key проверки во время импорта (если нужно)
- После импорта проверить целостность данных
